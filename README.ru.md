# MemPalace Retrieval

[English](README.md) · [MIT](LICENSE)

Небольшой модуль Python для поиска по памяти агента. Он помогает не подставлять в ответ устаревшие или недоступные факты. Модуль выделен из локальной надстройки над [MemPalace](https://github.com/MemPalace/mempalace) и хранилищем фактов. Соседний проект [Memory Ledger](https://github.com/alexandryasukaitisss-cmd/memory-ledger) хранит историю изменений фактов.

**Ищите по актуальным фактам.** Сначала исключите записи без доступа, отозванные и устаревшие. Затем объедините совпадения фраз, слов, векторов и свежих записей. Слабые совпадения пропустите, а перед выдачей ещё раз прочитайте исходную запись.

## Как попробовать

Нужен Python 3.11 или новее. Демо и тесты работают без базы, аккаунта, модели и сети.

~~~sh
python3 -B demo.py
python3 -B -m unittest discover -s tests -v
~~~

В демо время отправки меняется со вторника на четверг. Старый индекс перестаёт отвечать. Свежую запись можно найти ещё до перестроения индекса.

## Подключить к своему хранилищу

~~~python
from retrieval import IndexedMemory, Memory, search

fact = Memory("dispatch", "team", "2", "Окно отправки: четверг утром.", 1700000000)
store = {fact.memory_id: fact}
hits = search(
    "окно отправки",
    [IndexedMemory(fact)],
    read_current=store.get,
    allowed_scopes={"team"},
)
print(hits[0].memory.text)
~~~

Приложение передаёт разрешённые области доступа и функцию чтения исходной записи. Поисковый запрос не меняет права. Индекс хранит версию, область доступа, статус, время обновления и текст. Через **fresh** можно передать факты, которых ещё нет в индексе. Векторный поиск необязателен; модель, обработка и размерность векторов должны совпадать. Балл объединения рангов не означает вероятность правильного ответа.

Версия рассчитана на небольшие снимки в памяти. Она не открывает базу MemPalace и не запускает модель эмбеддингов. Приложение отвечает за согласованное чтение и проверку доступа при выдаче. Повторное чтение ловит изменения, замеченные до проверки. Пороги качества подберите на своих запросах. См. [отличия от локальной версии и атрибуцию](NOTICE.md).
